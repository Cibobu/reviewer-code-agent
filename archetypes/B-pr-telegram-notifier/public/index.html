🤖 GitHub Review Bot

Agent B — review PR & perbandingan branch via Telegram.

Status: checking…

Cara pakai

  1. Deploy server ini (HTTPS wajib)
  2. Set TELEGRAM_BOT_TOKEN + PUBLIC_BASE_URL di .env
  3. Buka bot Telegram → /start → /setup
  4. Ikuti wizard: repo, token GitHub, webhook
  5. Review otomatis dikirim ke chat Telegram Anda
